# Agentic Skills v1.0.0 — Multi-level Skill Tree

**Status: prepared locally; not published.**

**Prepared: 2026-10-14.**

This is the first versioned release of the redesigned library. It organizes the existing skill collection for browsing and strengthens repository maintenance; it does not represent a domain-by-domain rewrite of the skill instructions.

## Highlights

```text
12 categories
└── 65 subjects
    └── 724 topics
        └── 1,629 context / workflow groups
            └── 15,860 existing skills
```

- Explore the library through **803 navigation pages**, with expandable branches and breadcrumbs.
- Browse dedicated **Cybersecurity & Privacy**, **Healthcare & Medicine**, and **Music & Audio** categories.
- Read a refreshed README and a native, self-contained SVG banner with synchronized counts.
- Maintain the library with deterministic generation, safer migrations, local-link and anchor checks, and JSON validation reports.

## What changed for existing users

**3,677 package paths changed** during the category redesign. Skill names and instruction content were preserved. Topic grouping adds navigation depth without another package migration.

Use the [category migration receipt](../references/category-tree-migration-2026-10-14.csv) to map old paths to new ones. Old external bookmarks are not automatically redirected. The [current tree](../INDEX.md) replaces the old flat catalog table.

Files under `_topics/` are browsing indexes, not skills to install. Historical generators and reports may refer to the old layout or earlier totals; they are not the current inventory.

## Requirements

- An agent host capable of using the selected skill's instructions and authorized tools.
- **Python 3.10+** for repository maintenance commands. These commands use only the Python standard library.
- Individual workflows may need additional tools or services; review their instructions before use.

## Verification commands

Run these against the exact commit intended for publication:

```bash
python scripts/sync_catalog.py --check

python -m unittest discover -s tests -v
git diff --check
```

Local preparation checks passed: **76 tests**, **15,860 skills validated with zero issues**, and no generated-metadata drift.

The repository includes a Python 3.10/3.14 CI matrix. Local test results are not a substitute for completed remote checks. Structural validation is not a guarantee of domain correctness or live external-service compatibility.
